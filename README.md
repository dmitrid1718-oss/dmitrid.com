# Dmitri Doubovikov — Personal Portfolio

The personal portfolio and resume source for dmitrid.com.

Static HTML/CSS; no build process, analytics, cookies, or external dependencies. Open index.html locally or deploy the repository root to Vercel.

The professional history and resume are initial working drafts. Confirm dates, educational credentials, employment details, and product achievements before using this as a final job application.

## Portfolio photographs

The home page expects 18 optimized photographs in `assets/` (`01-fabric-structure.jpg` through `18-fabric-arch-build.jpg`). The photo bundle was prepared separately from the owner's original Wix export and must be uploaded to the repository's root `assets/` directory. Photo thumbnails are hidden until their files are present.

The page includes a subtle horizontal line texture and fine white borders around the photographs.
